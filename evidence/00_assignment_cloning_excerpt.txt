9.4: [1 point] Backup and Restore Strategy
Objective: Implement a backup and restore strategy using zero-copy cloning.
Steps:
Create a daily backup of the production database:
SQL
CREATE OR REPLACE DATABASE product_catalog_backup_{{ ds_nodash }}
CLONE product_catalog;
2. Implement an Airflow task to manage backups, keeping only the last 7 days:
Python
manage_backups = SnowflakeOperator(
    task_id='manage_backups',
    sql="""
    -- Create today's backup
    CREATE DATABASE IF NOT EXISTS product_catalog_backup_{{ ds_nodash }}
    CLONE product_catalog;
    -- Drop backups older than 7 days
    DROP DATABASE IF EXISTS product_catalog_backup_{{ macros.ds_add(ds, -7) }};
    """,
    snowflake_conn_id='snowflake_conn',
    dag=dag
)
3. Implement a restore procedure using the most recent backup.
